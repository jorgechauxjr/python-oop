### 🛠️ Conceptos de Python Aplicados
* **Definición de Clases y Atributos:** Uso correcto del método constructor `__init__`.
* **Herencia y Polimorfismo:** Creación de subclases para los distintos tipos de autos y licencias, reutilizando código de la clase madre.
* **Encapsulamiento en Python:** Manejo de atributos privados y protegidos usando guiones bajos (`_` y `__`).
* **Decoradores:** Implementación de Getters y Setters mediante `@property` para acceder y validar datos de forma segura.
