## Sistema de préstamos con identificación de usuarios en Python

Requerimientos del reto:

Desarrollar un programa que permita la identificacón de usuarios y la solicitud de libros en préstamo.

El sistema debe:
- Verificar la disponibilidad del libro
- Validar que no se excede el límite de préstamos permitidos
- Registrar el préstamo.

Al final debe mostra un mensaje de confirmación o en caso de incumplir las condiciones, debe mostrar un mensaje de error apropiado.
